# Minimal Nord Rice (Linux Mint XFCE)

Custom desktop configuration featuring:
- **Polybar**: Native IPC intellihide daemon, KDE Connect telemetry, Rofi notification viewer, battery limiter control.
- **Rofi**: Adi1090x Type-6 unified combi search (Windows, Apps, Commands, Files via `fdfind`) and Type-1 powermenu.
- **Navigation**: Dedicated Super key mapping via `xcape`.
- **System**: 80% battery charging threshold persistence, disabled default XFCE panel.
